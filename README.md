# AIS Rubric Feedback Generator

## Overview

This project was developed as part of a university team project to streamline assignment marking and feedback generation.

## Technologies

- ASP.NET Core MVC
- C#
- SQL Server
- Entity Framework
- Bootstrap

## My Contributions

I was responsible for:

- Developing the assessment and student marking interface
- Implementing the marking workflow using ASP.NET Core MVC
- Improving the UI layout and user experience
- Implementing score calculation and validation
- Integrating AI feedback through an API
- Testing and debugging the marking module

- MVC Architecture
- Database Design
- Git Collaboration
